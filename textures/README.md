# Upload your Poly Haven textures here

You downloaded the `*_4k.blend.zip` packages: good, they hold every map.

1. Unzip each one. Inside there is a `textures` folder with the `.jpg` maps (`..._diff_4k.jpg`, `..._nor_gl_4k.jpg`, `..._rough_4k.jpg`, `..._disp_4k.jpg`).
2. Make one folder here per texture, with exactly these names, and put that texture's `.jpg` maps inside:
   - `textures/white_plaster_rough_01/`
   - `textures/stacked_stone_wall/`
   - `textures/wood_planks/`
   - `textures/patterned_paving/`
   - `textures/marble_tiles/`
   - `textures/aerial_ground_rock/`
   - `textures/aerial_beach_01/`
3. On github.com: open this `textures` folder ▸ **Add file ▸ Upload files** ▸ drag the folder in ▸ **Commit changes**.

GitHub's website refuses files over **25 MB**. Some 4K normal maps are bigger: for those, download the **2K** version of that texture, or upload with GitHub Desktop (limit 100 MB). You don't need to upload the `.blend` file.
